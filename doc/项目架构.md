# 03 技术架构

## 一眼看懂

**一个 Vue 前端 + 一个 FastAPI 后端 + 一个 PostgreSQL 数据库。**

```text
员工 H5：录音学习 → AI 文字陪练 → 考试与自测 → 评分报告
管理后台：账号审核 / 录音发布 / 题目审核 / 成绩与成本
                         ↓
                    FastAPI 接口
                         ↓
        录音服务      陪练服务      考试服务
           ↓             ↑            │
      转写与分析         └──复用对练───┘
           ↓             ↓
       知识库 ←──── 求助与点评
                         ↓
        PostgreSQL（业务数据 + 向量 + 图检查点 + 员工记忆）
```

H5 可在浏览器直接使用，也可从企业微信工作台进入。当前以文字对练为主，语音输入与播放可选；企微消息是补充入口。前端构建后由后端托管。

## 三条业务流程

| 模块 | 流程 | 核心代码（backend/app/ 下） |
|---|---|---|
| 学习 | 导入录音 → 转写脱敏 → AI 分析 → 人工审核发布 → 员工学习 | `services/recordings.py` |
| 陪练 | 选场景 → 员工发言 → 评估 → 客户回复 → 结束生成报告 | `services/practice.py`、`graph/` |
| 考核 | 题库/听录音/对练组卷 → 保存作答 → 交卷评分 | `services/exams.py`、`exam_rules.py` |

正式对练考试复用陪练服务，禁用求助；自测允许求助。录音发布后将亮点话术写入知识库，取消发布时移除。知识库还支持 Markdown 导入。

## 改功能去哪里

| 内容 | 位置 |
|---|---|
| 员工页面 / 后台页面 | `frontend/src/views/` / `views/admin/` |
| HTTP 路由 / 登录与权限 | `backend/app/api/`，公共权限在 `api/deps.py` |
| AI 节点 / 信任值与评分规则 / 提示词 | `backend/app/graph/` / `graph/rules.py` / `prompts/` |
| 模型调用 / 知识检索 / 语音 | `backend/app/services/llm/` / `knowledge.py` / `speech.py` |
| 录音来源 / 文件转写 | `backend/app/services/recording_source.py` / `file_asr.py` |
| 数据表 / 费用落库 / 迁移 | `backend/app/db/models.py` / `db/usage.py` / `backend/migrations/` |
| 启动组装 / 环境配置 | `backend/app/main.py` / `core/config.py` |
| 场景 / 评分表 / 题库试卷 / 知识资料 | 根目录 `scenarios/` / `scenarios/rubrics/` / `exams/` / `knowledge/` |

## 保持简单的约定

- 接口接请求，服务管业务，LangGraph 管陪练步骤；考试直接复用陪练服务。
- 模型调用统一走网关，费用统一写入业务库；录音服务无需依赖陪练服务来记账。
- 本系统数据集中在 PostgreSQL + pgvector。外部业务库通过 dbmcp 导入录音来源，音频保留在对象存储。
- 检查点负责恢复 AI 流程，业务表负责查询与统计；网页断开后后台仍可继续生成报告。
- 保持单进程部署，会话锁在进程内；增加进程前需要调整锁机制。
- 录音发布和题目使用需审核；正式考试隐藏答案，练习中隐藏客户内心与信任值。
- 密钥和真实客户资料不提交 Git；视频使用虚构或已脱敏素材。
