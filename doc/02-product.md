# 02 产品方案

## 1. 用户角色

| 角色 | 诉求 | 使用方式 |
|---|---|---|
| 一线员工（客服/服务/售后/销售等） | 随时开口练客户话术，知道自己哪里不足 | 企业微信工作台进入 H5 语音对练 |
| 新人 | 快速上手、敢开口 | 低难度场景 + 求助提示 |
| 主管/培训负责人 | 了解团队练习情况与共性短板 | 管理看板（复赛阶段） |
| 业务专家/培训负责人 | 筛选成熟话术、定义评分标准 | 审核场景 YAML 与话术知识库 |

## 2. 核心功能

### 2.1 MVP（初赛必须）

1. **场景选择**：展示场景卡片（名称、难度、预计时长、客户性格简介）。
2. **对练对话**：
   - AI 扮演客户，按画像和隐藏状态做出反应。
   - 语音优先：支持“按住说话”输入，客户回复自动合成语音；文字作为无麦克风或安静环境下的备选。
   - 达成场景目标 / 客户挂断 / 轮数上限 / 主动结束后进入报告。
3. **求助提示**：员工卡壳时点"求助"，AI 教练给出简短提示（计入报告，提示次数影响得分）。
4. **评分报告**：
   - 总分 + 各维度得分（雷达图）。
   - 逐轮点评：亮点 / 问题 / 推荐话术。
   - 客户"内心独白"复盘：展示客户每轮信任值变化与真实想法（教学价值高，视频效果好）。
5. **历史记录**：查看自己的练习记录与分数趋势。

### 2.2 复赛扩展（可选）

- 闯关与排行榜（个人/部门）
- 管理者看板（练习人数、平均分、薄弱维度 Top3）
- 每日一练：企业微信消息推送，点击进入 H5 完成 3 分钟小场景
- 从业务系统中已授权、已脱敏的成熟话术批量生成候选场景，由业务专家审核后发布
- 新品资料一键生成练习场景
- 实时语音通话式陪练

## 3. 用户流程

```
企业微信工作台 → 点击“AI客户话术陪练”（OAuth 免登，识别工号/部门）
   → 场景列表（按部门推荐）
   → 场景说明页（客户背景、本次目标）
   → 对练页（语音/文字，多轮）
        ├─ 求助 → 教练提示
        └─ 结束
   → 评分报告页（总分、雷达图、逐轮点评、客户内心独白）
   → 再练一次 / 换场景 / 查看历史
```

## 4. MVP 场景清单（首批 3 个）

| 编号 | 场景 | 适用岗位 | 核心考察点 |
|---|---|---|---|
| S01 | 情绪激动的投诉客户（主演示） | 客服/服务 | 情绪安抚、问题解决、合规表达 |
| S02 | 需求模糊的咨询客户 | 客服/服务 | 需求澄清、准确解答、服务引导 |
| S03 | 催问处理进度的客户 | 客服/售后/服务 | 进度说明、预期管理、主动回访 |

当前均为脱敏虚构示例。后续以业务系统中的成熟客服话术为依据，经授权、脱敏、业务专家筛选后替换，见 `05-data-and-security.md` 和 `07-open-questions.md`。

## 5. 体验原则

- 一次练习控制在 3~8 分钟，碎片时间可完成。
- 移动端优先，按钮大、字少。
- 报告先给结论（总分与一句话评价），再给细节。
- 鼓励为主：每份报告至少给出 1 个亮点。
