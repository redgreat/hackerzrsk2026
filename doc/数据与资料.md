# 05 数据接入与安全

## 当前知识提取方案（试标中）

以优秀录音为唯一真实案例入口，优先复用已有转写。先按来源标识去重并保留完整导入快照，再提取连续沟通事件；当前不涉及 Wiki。

| 层次 | 保存什么 |
|---|---|
| 案例 | 来源标识、导出快照、原文哈希、原始片段编号/声道/时间值、角色映射及核验状态 |
| 知识事件 | 原文范围、必要上下文、证据编号、提炼总结、标签、适用边界、审核及检索状态 |

标签先限定为四类：客户问题、沟通阶段、坐席动作、可观察结果。允许“其他/无法判断”，优秀标签保留为源系统标记，不直接视为片段结论。

保留否定、不确定、纠正和后续反应；重复语气词可在展示时折叠，原始快照不删除。总结与原话分开，沟通反馈与还款/审批结果分开。角色未核验、关键 ASR 存疑或具体政策未核验的内容不得直接成为正式答案。

私有试标见 [试标说明](../data/private/knowledge-pilot/试标说明.md) 和 [结构化示范](../data/private/knowledge-pilot/提取示范.json)：两份已有转写快照、三个事件。当前全部待审核且未启用检索，尚未写入系统数据库。核对样例后再实现批量提取与落库。

| 数据 | 存放与使用 |
|---|---|
| 虚构场景、示例话术、题库 | `scenarios/`、`knowledge/`、`exams/`，可提交 Git |
| 本地原始资料 | `data/private/`，禁止提交 Git |
| 真实录音 | 音频保留在对象存储；系统数据库保存地址和处理结果，需权限控制 |
| 转写、点评、题目 | 转写按现有规则脱敏后落库；分析结果和发布内容还需人工审核 |
| 密钥 | `.env`，禁止写入代码、日志或演示画面 |

录音处理：授权来源 → 导入地址 → 转写脱敏 → AI 分析 → 人工审核 → 发布学习内容与知识片段。取消发布会移除对应录音知识片段。

脱敏函数不能保证识别所有姓名、地址或业务秘密，演示资料必须人工检查。音频本身不会因转写脱敏而自动脱敏；视频使用虚构或已脱敏且获准展示的素材。

知识库中的示范时间、技术进度和处理方式是虚构情境，不能作为真实业务事实或权限承诺。正式资料应经业务确认，保留来源与适用条件。
