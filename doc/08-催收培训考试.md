# 08 催收培训考试

## 题库与自动组卷

在「考试管理 → 考试题库」选择已发布的练习，点「AI 生成合规题」。系统把练习背景、目标与适用评分标准交给模型，生成单选题、考点和解析。生成时会参考已有考点，入库时跳过重复考点和相近题干。管理员核对选项、答案与解析后，可设为可用或归档。

选择题存入 PostgreSQL 的 `exam_questions`，保留来源练习。试卷模板由 `exams/papers/` 下的 YAML 定义题量、权重、时限和及格线。学员每次新开答卷时随机抽题，只使用已审核且来源仍发布的题目。同一份答卷内不重复抽题，题量不足时提示补充题库。

开考时把题目、参考答案、试卷规则及对练评分表存入答卷快照。刷新继续使用原答卷，题库变动仅影响之后的新答卷。已发布的旧版答卷仍可读取。

## E01 催收新人上岗考试

- 合规与话术知识抽 12 题，占 40%。
- 从已发布且未归档的录音练习里抽两场文字情景对练，占 60%。
- 60 分钟，最多 3 次，80 分及格。正式考试中的对练禁用求助。

## 学员作答和成绩

选择题随作答保存，刷新后可以恢复。完成情景题后返回试卷。交卷时仍在进行的对练会生成报告，未开始的场景按零分处理。评分失败可以重试交卷。成绩页展示总分、是否通过和各部分分数，管理员可通过「考试成绩」查看答卷。

当前考试入口只开放 E01。页面操作见 [功能文档](功能文档.md#考试与自测)。
