# 03 技术架构

Vue H5 与管理后台由 FastAPI 提供接口。构建后的前端由后端托管。PostgreSQL 保存业务记录、对话检查点、试卷快照和知识数据。LangGraph 编排对练，模型网关统一调用和统计用量。

## 对练处理

接收员工发言后，先判定相关性，再评估信任值和顾虑是否化解。明显跑题或评估为无关的话直接获得提醒，发言留在记录中，轮次和信任值保持原值。相关发言进入客户模型，完整回复检查后才返回页面。员工主动结束或达到场景结束条件后，由教练生成报告，评分请求超时可以重试。

会话以检查点恢复。当前会话锁按单进程工作。录音派生场景与考试题库存于 PostgreSQL，评分表用 YAML 配置。开考时保存本次答卷快照。

## 本分支的运行配置

本机可由 PowerShell 启动脚本拉起 Docker PostgreSQL、构建前端并启动后端。服务器 Compose 包含应用与 PostgreSQL，使用 GHCR 镜像，配置位于根目录及后端的 `.env`。本分支最新迁移为 `0007_exam_question_bank`。企业微信接入和生产部署命令见 [项目说明](../项目说明.md)。
